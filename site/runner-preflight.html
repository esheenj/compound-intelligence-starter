    03 / Move from this worksheet to the Rust binary
    

    The released Runner Preflight v0.2.0 preview accepts inspect --input FILE --format json. Exit codes are 0 READY, 1 WARN, 2 HOLD, and 3 invalid input. Linux x86-64 and ARM64 binaries were compiled and tested from the extracted standalone source on GitHub Actions.
    

    New in v0.2.0: the downloadable standalone source includes an opt-in, Python 3 standard-library Linux observer. On a machine you authorize, it can collect disk and memory availability, OS/architecture and the presence of requested executable names, then pass that local JSON to Rust. It cannot verify registered runner labels, installed Rust targets, tool versions or GitHub scheduling. This browser page still uses only synthetic supplied inventories and does not inspect your device.
    

    This page is a separate JavaScript reference implementation, not Rust compiled to WebAssembly. The three example scenarios and errors are checked for parity in project CI. It does not have control-plane, Oracle, trading or AI agent permissions.
