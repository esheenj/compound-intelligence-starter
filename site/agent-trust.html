3. What's still needed for real agent verification?

This browser compares a caller-supplied registry with caller-supplied claims. Its SHA-256 checksum verifies only consistency of supplied bytes; anyone can generate a new checksum. Even “self-reported signed” is just an assertion. An authentic solution requires independent public-key challenge verification, trusted registry issuance, durable nonce replay protection, trusted time, key revocation, scoped authorization and server-side enforcement.

It runs without network calls or storage. See the Python reference, tests and boundaries and Wave 3 tracker.
