    3. Trust boundary

    SHA-256 consistency can detect accidental or unauthorized alteration relative to a trusted digest. It cannot establish whether the original digest or claimed producer was trustworthy. Actual identity attestation needs a separately verified signing key, signature, scoped permissions and replay-safe trusted receipt source.

    The browser version accepts a restricted JSON subset with safe integer numbers and a maximum of 100 events; it rejects duplicate JSON keys. Use the Python reference implementation and its tests for the broader source contract. This page stores nothing and transmits nothing.
