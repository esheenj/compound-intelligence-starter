# Community conduct

We welcome good-faith contributions from people with different skill levels and experiences. Keep discussions respectful, constructive and focused on reproducible evidence.

- Critique the idea, claim or implementation, not the person.
- Give contributors room to ask beginner questions and receive actionable feedback.
- Avoid harassment, threats, discriminatory remarks, impersonation, spam and sharing private information.
- Do not post credentials, customer data or private code in issues or pull requests.
- Report concerning conduct privately to the repository maintainer using GitHub's available private contact options. Security vulnerabilities should be reported through [security guidance](docs/SECURITY.md), not public exploit details.

Maintainers may edit or remove abusive content and restrict participation when necessary.
