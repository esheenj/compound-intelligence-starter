# Compound Intelligence: Don't Just Use Intelligence. Compound It.

I've been experimenting with a different approach to AI: not just prompting smarter models, but connecting intelligence, tools, memory, and automation into systems that can improve through verified iterations.

Imagine AI that doesn't restart its work from zero every session. It can explore ideas, challenge assumptions, build solutions, run experiments, learn from failures, and carry validated discoveries forward.

**Multiple models. Different strengths. Shared knowledge. Continuous execution.**

The building blocks are accessible today: [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/), [Ollama](https://ollama.com), [Claude Code](https://code.claude.com/docs/en/overview), [ChatGPT / Codex](https://chatgpt.com/codex), and [GitHub Actions](https://docs.github.com/en/actions).

**Discover → Reason → Build → Validate → Learn → Improve → Repeat.**

One model makes a discovery. Another challenges it. Tools test it. Supported outcomes become reusable evidence. Failures inform the next attempt. The opportunity is not magic autonomy, but less repetition, better experimentation, and a more reliable path from ideas to measurable progress.

This repository includes a small runnable, dependency-free demonstration of that principle, without relying on proprietary services.

**Don't just use intelligence. Compound it.**
