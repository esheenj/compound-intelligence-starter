# Public release boundaries

This repository intentionally contains only generic educational logic and public product links.

Do not commit private hostnames, IP addresses, tokens, credential files, SSH keys, signing policy, company-specific datasets, user records, trading execution code, production strategy parameters or privileged Commander control-plane material.

Any future model or tool connector must use least privilege, opt-in external operations, input validation, bounded costs and independent validation. Never treat model-generated instructions as authorization. Public forks should audit their own changes and dependencies before deployment.

To report a potential security issue, avoid publishing exploit details or credentials in an issue. Contact the maintainer through GitHub's available private reporting facilities.
