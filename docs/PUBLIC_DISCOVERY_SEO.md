# Public gallery discovery — source and hosting limits

## What changed

The public Esheen Labs GitHub Pages directory now ships a source-reviewed project sitemap at:

https://esheenj.github.io/compound-intelligence-starter/sitemap.xml

It lists **15 existing published pages** only, including the gallery home page, the commercial Integration Reliability landing page, original on-site playgrounds and the support page. The sitemap does **not** list the 22 independently hosted repositories as if they belonged to this project; each independent repository owns its own publishing path.

The directory homepage has an exact canonical URL, human-readable Sitemap link and basic Open Graph/Twitter text metadata. No new product, published repository, browser demo, tracking script, advertising system, domain, subscription or backend is introduced. Counts remain **22 independent public repos / 43 existing public demo entries**.

A project-scoped `robots.txt` is also published at `/compound-intelligence-starter/robots.txt` with a pointer to the sitemap. **Search engines normally consult only the hostname root** (`https://esheenj.github.io/robots.txt`) for robots exclusion. This project-scoped copy does not grant authority over that root file and must not be presented as a crawl rule that search engines automatically honor.

## Publication gates

- Exact static sitemap and robots bytes generated by `scripts/public_discovery.py` using a reviewed allowlist of public pages
- Reject incorrect URL hosts, duplicated or missing entries, unreviewed robots directives, noindex source pages, and unrecognized file substitutions
- `scripts/stage_showcase.py` verifies both sources before copying byte-for-byte into the isolated public Pages artifact, with SHA-256 and counts in the receipt
- GitHub Actions Python and Chrome tests verify the index's canonical target, sitemap link, data boundary and responsive layout
- Postpublish read-only acceptance checks the *actual HTTPS* sitemap, exact public hashes and HTTP 200 for all 15 listed pages
- A passed CI check is not a claim of successful deployment; a live check is required
- No real customer interaction, payment or message is sent by the verification process

## What remains unverified

**Search Console ownership, sitemap submission, indexing, rankings, search impressions, conversions, traffic and qualified inbound leads are not verified.** A published sitemap alone cannot force search engines to index pages.

The main business domain `sigmacode.co.za` is served separately through ChatGPT Sites and was **not edited** during this change. Its robots and Search Console configuration should not be inferred from the GitHub Pages project. The existing business site already links to the public gallery, and the verified customer landing page is still `/compound-intelligence-starter/integration-reliability.html`.

If the user later authorizes an appropriate GitHub Pages **hostname-root** repository and its actual ownership, that would be the right place to manage `https://esheenj.github.io/robots.txt`. Do not create or replace the root site blindly.
