# v0.5 — Capability benchmark reports

A reusable, **bounded** benchmark harness aggregates results from the existing typed challenge runner. It measures exact-match success and failures without treating unsupported claims as validated.

## Try without a model

```bash
python -m src.compound_intelligence.benchmark --fixture --output local-data/report.json
python -m src.compound_intelligence.benchmark --fixture --output local-data/report.json
python -m unittest discover -s tests -v
```

Results are labeled `SIMULATED_FIXTURE` and contain per-model scores, counts by task type, a dataset SHA-256 digest, experiment version and individual outcomes. Repeating a run reuses its SQLite records. To run again with new proposals, supply a new `--version`; editing the input dataset changes the identity automatically.

## Opt-in local model comparison

```bash
python -m src.compound_intelligence.benchmark --models YOUR_OLLAMA_MODEL_A YOUR_OLLAMA_MODEL_B
```

Only locally running Ollama is contacted. There is no automatic model installation or remote provider usage. Replace the example JSON dataset via `--tasks path/to/challenges.json` after reviewing the dataset format in [v0.4](V0.4.md).

## What the reported metrics mean

- **Attempted:** every task/model pairing, including unavailable responses.
- **Completion rate:** portion producing a validatable proposal rather than `NO_RESULT`.
- **Verified per attempt:** strict correct-answer rate including missing attempts.
- **Exact match given answer:** share of answers accepted among attempts that produced a proposal.
- **Wilson 95% interval:** an illustrative binomial score interval around verified-per-attempt; on a tiny, selected dataset it is **not** a credible measure of broader model ability.
- **Per-type breakdown:** separates static code-patch reference matching from factual extraction.

**Important:** The reference text is omitted from model prompts, but the reference answers are present in local input files. This is not a secret benchmark service. Static patches are never executed. The fixture mode is simulated. No claim of model generalization, causally improving intelligence or autonomous software engineering follows from these scores.

## Next
