# v0.4 — Validated practical tasks (bounded)

## Try offline

```bash
python -m src.compound_intelligence.problem_runner --fixture
python -m src.compound_intelligence.problem_runner --fixture
python -m unittest discover -s tests -v
```

The runner compares two *simulated* proposers across two examples: extracting return policy details from a fictional store notice and proposing a textual correction to a buggy Python function. It records exact-match validation outcomes transactionally, then reuses them on the next run.

## Try local Ollama

```bash
python -m src.compound_intelligence.problem_runner --models YOUR_LOCAL_MODEL_A YOUR_LOCAL_MODEL_B
```

Model output is treated as untrusted **proposals**. The reference answers are withheld from the model prompt. Only the independent typed validators determine pass or fail. The software makes local-only HTTP calls to Ollama, never executes suggested source code, and performs no autonomous tool actions.

## Adding a challenge

Create a JSON list of tasks with stable IDs, either:

- `extract`: `text`, `fields`, `expected` (typed exact-match dictionary).
- `patch`: `source`, `instruction`, `expected` (static reference output after exactly one old/new replacement).

Then use `--tasks your-challenges.json`. The private benchmark reference exists in that local JSON file, but is **not sent to Ollama** by this runner. Don't publish private benchmarks or sensitive data.

## Limitations

Static patch validation does **not** demonstrate correctness of executable programs or dynamic tests. Extraction uses exact expected answers and has no probabilistic scoring, information retrieval, or independent semantic review. A successful result only verifies the specific fixture. Results are keyed by task content, model identifier and explicit `--version`; reruns reuse prior records (including unavailable models). Use a new version identifier to attempt a fresh run. SQLite stores local evidence; it is not a tamper-proof audit log.

Model adapters are intentionally opt-in. GitHub Actions verifies simulated proposals, not live Ollama availability or real model quality. Zero required subscriptions and no production execution privileges.
