# v0.2 — Bounded model-assisted experiments

This release adds a separate opt-in research runner while keeping the original v0.1 demo unchanged.

## Run without any model

```bash
python -m src.compound_intelligence.runner --input examples/experiments.json
python -m src.compound_intelligence.runner --input examples/experiments.json
python -m unittest discover -s tests -v
```

The second run reports `new: 0` because SQLite has already saved and matched the experiment IDs and input digests. Reusing an ID with different inputs raises an error rather than overwriting evidence.

## Optional local-model challenger

First install and start [Ollama](https://ollama.com) and pull a model of your choice. Then:

```bash
python -m src.compound_intelligence.runner --ollama-model YOUR_LOCAL_MODEL
```

The model provides **advisory critique only**. Independent validation remains a bounded Python arithmetic check; model output cannot execute commands or turn a rejected result into verified evidence. The Ollama adapter only connects to a local HTTP address, with response-size and timeout limits.

## Boundaries

This is an intentionally narrow working slice, not arbitrary task autonomy. It does not perform code edits, shell execution, unattended scheduling, or model-generated experiments. The current validated task type is integer addition. SQLite supports transactional duplicate prevention, but this design does not claim globally tamper-proof provenance. Future phases can introduce safe plugins, model proposals, stronger evidence verification, and explicit permissioned tool access.
