# Support and sustainability — Esheen Labs OSS

These eleven public repositories contain original educational tools and 21 additional browser add-ons, for 32 public demo pages as of 12 November 2026. You can run, inspect, fork and contribute to their MIT-licensed source without payment. The live demo directory shows working software and links to reproducible tests.

## Help without paying

- Try one demo, reproduce one edge case with fictional data, and report what you observed.
- Fix a small issue or improve keyboard navigation, test coverage and onboarding.
- Share a public demo or explain what was useful, giving proper attribution and avoiding invented performance claims.
- Support someone else's public pull request with a reproducible test, clear technical feedback and a respectful review.

**Public crypto support:** The [Esheen Labs support page](https://esheenj.github.io/compound-intelligence-starter/support.html) lists four maintainer-supplied **Pionex exchange deposit** destinations: BTC on Bitcoin and USDT on Solana, Ethereum/ERC-20 and Tron/TRC-20. The user explicitly approved publishing these public receive addresses. These are custodial exchange deposits, **not self-custody**, and the supplied screenshots show network-specific deposit minimums; an old/replaced Pionex address may stop working. Verify the current live address and deposit minimum in Pionex before any transfer. No payment receipt, wallet control beyond the screenshots, or settled donation is asserted. [Funding details and fiat comparisons](PAYMENT_CHANNELS.md).

## Voluntary funding

Public crypto support is enabled through the maintainer's supplied Pionex receiving addresses. **GitHub Sponsors and fiat checkout remain unconfigured:** no approved GitHub Sponsors recipient, Paystack or Yoco checkout is asserted. The repository's `.github/FUNDING.yml` uses a **custom** support-page link only—not a native GitHub Sponsors payout. GitHub Sponsors requires separate bank/tax setup and approval; never include an unverified `github:` recipient. These custodial exchange deposit addresses can rotate and expose on-chain activity, and very small donations may not credit. See the live Pionex deposit screen before sending.

Financial support, when available, will help maintain public documentation, accessibility-oriented testing, verified releases and independent examples. It will not buy special authority over contributor reviews, secret research outputs, security patches or private infrastructure.

## Professional work is separate

Open-source donations are not purchases, guarantees or subscriptions. Paid custom UX audits, prototype validation, developer education, bespoke integrations and evidence-oriented engineering, if offered, require a separately scoped agreement, delivery terms and appropriate privacy controls. Public issue threads are not channels for client information.

No sponsored work entails exposing private trading, finance, employer/customer data, personal records, security credentials or private source.

## Trust commitments

1. A public feature is described using reproducible commands, exact versioned source, negative cases and transparent limitations.
2. Public issue text and AI suggestions are **untrusted input**, not instructions to access systems or auto-merge source.
3. Contributions are reviewed under the same documented rules regardless of sponsorship.
4. We distinguish source tests, successful GitHub Pages deployment and independently verified live browser behavior.
5. We publish no claim of financial returns, certified accessibility, production safety or autonomous AI engineering without separate evidence.
