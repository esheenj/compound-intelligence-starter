# v0.3: Compare multiple proposals with independently validated evidence

## No-model demonstration

```bash
python -m src.compound_intelligence.tournament --fixture
python -m src.compound_intelligence.tournament --fixture
```

The first run compares two **simulated** proposers: a correct one and a deliberately incorrect one. The next run reuses saved SQLite evidence without querying models again.

## Optional local Ollama models

Install and run Ollama and download the selected models first. Then:

```bash
python -m src.compound_intelligence.tournament --models model-a model-b --values 8 13
```

The models each propose an answer in a bounded JSON response. They never decide which answer is true: a trusted deterministic sum validates every candidate.

## Important limitations

- This is a **model comparison for bounded arithmetic**, not general-purpose multi-agent research or self-improving intelligence.
- A verified proposal means the answer to this particular arithmetic input was correct. It is not evidence that the model is generally reliable.
- The sample can use two or more local models, but model invocation and its prompt are deliberately basic, not a production model router.
- Ollama is contacted only at the local HTTP endpoint. Missing or invalid responses become `NO_RESULT`; they do not become knowledge.
- Models run sequentially, limited to 8 per invocation, each with a timeout and response-size limit.
- Experiment records are keyed to the task and model name. Replaying does not rerun a model. To compare a different model version under an otherwise identical name, use a distinct model tag or clean workspace.
- No automatic external execution, credentials, network crawling or shell access is provided.
